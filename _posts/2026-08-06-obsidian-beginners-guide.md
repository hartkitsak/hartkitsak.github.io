เคยไหมที่จดโน้ตไปเยอะ แต่พอจะหาข้อมูลเก่ากลับหาไม่เจอ? Obsidian เป็นแอปจดโน้ตที่ถูกออกแบบมาแก้ปัญหานี้โดยเฉพาะ — ไม่ใช่แค่ที่เก็บข้อความ แต่เป็น **ระบบเชื่อมโยงความคิด** ที่ทำให้นิยามตัวเองบนหน้าเว็บว่า *"Sharpen your thinking"* (ทำให้ความคิดคมขึ้น)

## Obsidian คืออะไร

Obsidian คือแอปจดโน้ตแบบ **local-first** — ไฟล์ทั้งหมดเป็น Markdown เก็บอยู่ในโฟลเดอร์บนเครื่องเรา (เรียกว่า **vault**) ไม่มีระบบคลาวด์บังคับ ไม่ล็อกข้อมูล

จุดขายหลัก:
- **ฟรีสำหรับใช้ส่วนตัว ไม่จำกัด** — หน้า pricing เขียนว่า *"Free without limits. No sign-up required."*
- **ไฟล์เป็นของเรา 100%** — เปิดด้วยโปรแกรมอะไรก็ได้ แม้ Obsidian หายไป ข้อมูลก็ยังอยู่
- **การเชื่อมโยงความคิด** — ลิงก์โน้ตหากันด้วย `[[...]]` แล้วเห็นภาพรวมใน Graph View

## เริ่มต้น 3 ขั้น

### 1. โหลดและสร้าง vault

ไปที่ [obsidian.md](https://obsidian.md) → Download (มี Windows / macOS / Linux / iOS / Android) → เปิดแล้วเลือก **Create new vault** → ตั้งชื่อ → จบ ระบบจะสร้างโฟลเดอร์ว่างๆ ไว้ให้

### 2. รู้จักหน้าจอ

- **ซ้าย:** File Explorer — รายการไฟล์ใน vault
- **กลาง:** ตัวแก้ไข — พิมพ์โน้ต
- **ขวา:** Backlinks / Graph View / อื่นๆ

### 3. เขียนโน้ตแรก

สร้างไฟล์ `.md` ใหม่ พิมพ์ด้วย Markdown พื้นฐาน:

```markdown
# ชื่อหัวข้อ

นี่คือโน้ตแรกของฉัน **ตัวหนา** *ตัวเอียง*

- รายการที่ 1
- รายการที่ 2

[ลิงก์ไปเว็บ](https://example.com)
```

กด `Ctrl+E` สลับโหมดแก้ไข/พรีวิว (บน Mac ใช้ `Cmd+E`)

## หัวใจของ Obsidian: ลิงก์ ไม่ใช่โฟลเดอร์

ใน Obsidian ไม่ต้องจัดโครงสร้างโฟลเดอร์ให้เพอร์เฟกต์ — เพราะตัวเชื่อมหลักคือ **ลิงก์**:

```markdown
# สรุปหนังสือ Deep Work

แนวคิดหลักของ [[ความสนใจแบบลึก]] คือ...
```

พิมพ์ `[[` แล้วเลือกโน้ตที่จะลิงก์ — Obsidian จะสร้าง:
- **Backlinks** — ดูว่าโน้ตไหนลิงก์มาหาเรา (โน้ตไหน "อ้างถึง" เราบ้าง)
- **Graph View** — แผนภาพความคิดทั้งระบบ เห็นว่าโน้ตไหนเชื่อมกับอะไร

หลักการง่ายๆ: **คิดเป็นโน้ตหนึ่งเรื่องหนึ่งไฟล์** แล้วลิงก์หากัน — ยิ่งลิงก์เยอะ ยิ่งเห็นภาพใหญ่ชัด

## Plugins — จุดที่ทำให้แรงกว่า Notion/Evernote

Obsidian มี plugin ทั้งในตัวและจากชุมชน (1,000+ ตัว):

| Plugin | ใช้ทำอะไร |
|---|---|
| **Daily Notes** | สร้างโน้ตประจำวันอัตโนมัติ |
| **Templates** | แม่แบบโน้ตซ้ำๆ (เช่น บันทึกประชุม) |
| **Canvas** | เขียนไอเดียแบบฟรีฟอร์มบนกระดาน |
| **Dataview** | ดึงข้อมูลจากโน้ตมาเป็นตาราง/รายการ |
| **Kanban** | จัดการงานแบบบอร์ด |
| **Excalidraw** | วาดไดอะแกรมในตัว |

คำแนะนำสำหรับมือใหม่: เริ่มจาก plugin ในตัวก่อน ค่อยๆ เพิ่มตามความต้องการ — อย่าโหลดพรวดเดียว เดี๋ยวจะล้น

## ข้ามเครื่องและเผยแพร่

- **ฟรี:** ใช้ git / Syncthing / ระบบ cloud ใดก็ได้ sync โฟลเดอร์ vault เอง
- **Obsidian Sync** ($4–5/เดือน) — ซิงก์ทางการ เข้ารหัส end-to-end มีประวัติเวอร์ชัน
- **Obsidian Publish** ($8–10/เดือน) — เผยแพร่โน้ตเป็นเว็บไซต์ ไม่ต้องเขียนโค้ด

## ราคา — ฟรีจริงไหม

**ฟรีจริงสำหรับใช้ส่วนตัว** ไม่จำกัดฟีเจอร์ (ต่างจาก Notion ที่คิดเงินถ้าส่วนตัวเกิน) ส่วนที่เสียเงินเป็น**บริการเสริม**:

| บริการ | ราคา | จำเป็นไหม |
|---|---|---|
| แอปใช้ส่วนตัว | **ฟรี** | — |
| Sync / Publish | ~$4–5 / ~$8–10 ต่อเดือน | ไม่จำเป็น มีทางฟรี |
| Commercial license | $50/คน/ปี | ไม่บังคับ (บริษัทควรซื้อช่วย support) |

## ข้อควรรู้ก่อนเริ่ม

1. **ต้องคุ้น Markdown หน่อย** — ถ้าไม่เคยใช้ มีเส้นโค้งเรียนรู้เล็กน้อย แต่ไม่ถึงชั่วโมงก็ชิน
2. **ความลับ** — เพราะไฟล์อยู่บนเครื่องเราเอง อย่าลืมเรื่อง backup (มี plugin อัตโนมัติให้) และถ้า sync ผ่าน cloud ส่วนตัว ข้อมูลก็อยู่ใต้การดูแลของเราเอง
3. **ไม่ใช่ Google Docs** — เดิมทีเน้นคนเดียว (collab แบบเรียลไทม์ต้องผ่าน Sync shared vault) แต่จุดแข็งที่แท้จริงคือการเป็น "สมองที่สอง" ส่วนตัว

## สรุป

Obsidian คือแอปจดโน้ตที่ **ฟรี เก็บข้อมูลในเครื่อง เปิดกว้างด้วย plugins และให้อิสระเต็มที่** เหมาะกับคนที่จดเยอะ ทำงานกับความคิด หรืออยากสร้างระบบความรู้ของตัวเองแบบจริงจัง เริ่มแค่วันละ 10 นาที: สร้าง vault, เขียนโน้ตแรก, ลิงก์โน้ตเข้าหากัน — แล้วคุณจะเห็นว่าการจดบันทึกไม่เคยรู้สึกเป็นระบบขนาดนี้มาก่อน

ถ้าเคยใช้ LM Studio จะรู้ว่ามันคือแอปดาวน์โหลดโมเดล AI มารันบนเครื่องตัวเอง สะดวกดีแต่จำกัดอยู่ที่ "คุยได้ แต่ทำงานแทนไม่ได้" กลางเดือนกรกฎาคม 2026 ทีม LM Studio ปล่อยตัวใหม่ชื่อ **Bionic** ที่ข้ามเส้นนั้น — ไม่ใช่แชทบอทที่มีเครื่องมือติดมาแบบหวัดๆ แต่เป็น **เอเจนต์เต็มตัว** ที่อ่านไฟล์ แก้โค้ด รันคำสั่ง และสร้างเอกสารได้จริง บทความนี้สรุปจากเอกสารทางการและข้อมูลใน changelog

## Bionic คืออะไร

Bionic คือ **แอปแยกต่างหากจาก LM Studio** (ตัวรันโมเดลเดิมยังอยู่ครบ ใช้คู่กันได้) ออกแบบมาเพื่องาน agentic กับโอเพนซอร์สโมเดลโดยเฉพาะ — ทั้งเขียนโค้ด งานวิจัย และงานเอกสารที่ซับซ้อน จุดขายคือเราเลือกได้ว่าจะให้โมเดลรันที่ไหน และคุมความเป็นส่วนตัวกับค่าใช้จ่ายได้เอง

## ทำอะไรได้บ้าง

**ด้านโค้ด:**
- สร้าง **Project** สำหรับ codebase แล้วเปิดหลาย session แยกงานกัน — รันขนานหลายโปรเจกต์พร้อมกันได้
- ตรวจไฟล์ในโปรเจกต์ รันคำสั่ง shell แก้ไขโค้ด พร้อมระบบ **checkpoint** ที่ย้อนกลับการเปลี่ยนแปลงได้
- โหมดความปลอดภัยของ shell ปรับได้ 4 ระดับ: ปิด / ตรวจเองทุกคำสั่ง (manual review) / **Auto Review** (ให้ตัวใหญ่ตรวจคำสั่งของตัวเล็ก) / อนุญาตหมด

**ด้านเอกสารและงานทั่วไป:**
- Work project สำหรับเอกสาร งานวิเคราะห์ งานวิจัย — ไฟล์ถูกประมวลผลใน sandbox พร้อม checkpoint อัตโนมัติ
- สร้าง **เอกสาร, สไลด์, PDF, สเปรดชีต** ได้จากโจทย์ที่พิมพ์ให้
- **Vision subagents** — ให้โมเดลข้อความล้วนมองเห็นรูปได้ โดยส่งต่อให้โมเดล vision อีกตัวประมวลผล
- แชทแบบไม่ต้องสร้างโปรเจกต์ (project-less chats) ในเวอร์ชัน 1.1.0
- พิมพ์ด้วยเสียงและถอดเสียงได้

## โมเดลรันที่ไหนได้ — เลือก 3 แบบ

| ที่รัน | เหมาะกับ | เรื่องข้อมูล |
|---|---|---|
| **Local** — บนเครื่องเรา | งานประจำ ความเป็นส่วนตัวสูงสุด | ข้อมูลไม่ออกจากเครื่อง |
| **LM Studio Secure Cloud** — โมเดลโอเพนซอร์สระดับแนวหน้า | งานหนักที่เครื่องไหว | **Zero Data Retention** — ไม่เก็บข้อมูล request |
| **LM Link** — ดึงโมเดลจากอีกเครื่องของเรา | มีเครื่องแรงไว้ที่อื่น | อุโมงค์เข้ารหัสระหว่างอุปกรณ์ |

แถมเรื่องประสิทธิภาพ: เอนจินใหม่รองรับทั้ง llama.cpp และ MLX (Mac) — ในเวอร์ชันล่าสุด prompt processing บนเครื่อง M5 เร็วขึ้นถึง **2–2.75 เท่า** ด้วย disk cache

## เวอร์ชันล่าสุด (1.1.0, สิงหาคม 2026)

ปล่อยครั้งแรกกลางเดือน ก.ค. 2026 แล้วอัปเดตถี่มาก ของที่เด่นใน 1.1.0:
- Auto Review สำหรับคำสั่ง shell + ลดการถามอนุมัติงานที่ปลอดภัย (อ่านไฟล์, query GitHub แบบ read-only)
- Project-less chats และย้าย session ข้ามโปรเจกต์ได้
- Vision subagents
- รองรับรูปใน tool call results ผ่าน API มาตรฐาน (/v1/chat/completions ฯลฯ)

## เทียบกับ Freebuff แบบคร่าวๆ

อาจสงสัยว่าต่างกันแบบไหน — คำตอบสั้นๆ: **Freebuff คือเอเจนต์ฝั่งคลาวด์ที่ฟรี**, Bionic คือเอเจนต์ฝั่ง local-first ที่เน้นคุมข้อมูลเอง

| | Freebuff | LM Studio Bionic |
|---|---|---|
| รันโมเดลที่ไหน | คลาวด์ของบริการ | เครื่องเรา / คลาวด์ ZDR / เครื่องอื่นผ่าน LM Link |
| ค่าใช้จ่าย | ฟรี (รายได้จากโฆษณา) | แอปใช้ได้กับโมเดล local ฟรี, คลาวด์จ่ายตามใช้งาน |
| จุดแข็ง | เริ่มง่าย ไม่ต้องมีเครื่องแรง | ความเป็นส่วนตัว, ความยืดหยุ่น, ใช้โมเดลอะไรก็ได้ |
| เหมาะกับ | มือใหม่ / งานทั่วไป | งานลับๆ, โค้ดส่วนตัว, คนมีการ์ดจอ |

## ข้อควรรู้ก่อนใช้

พูดตรงๆ ตามที่ผู้ใช้และรีวิวต่างๆ ชี้กัน:
- **เครื่องต้องแรง** — โมเดล local ต้องการ RAM/VRAM และพื้นที่มาก โมเดลเล็กฟรีแต่ความสามารถต่างจากตัวใหญ่ชัดเจน
- **ZDR ไม่ใช่ความปลอดภัย 100%** — ใช้คลาวด์ = ข้อมูลออกนอกเครื่องแน่นอน แม้เขาจะไม่เก็บก็ตาม งานที่ไวต่อข้อมูลควรใช้ local ล้วน
- **Checkpoint ไม่ใช่ Git** — ควรมี version control และ backup ของจริงคู่กันเสมอ
- **เอเจนต์รัน shell ได้** — พลังนี้มีความเสี่ยงในตัว ถ้าข้อมูลหรือโค้ดมีคำสั่งปลอมปนมา อ่านคำสั่งก่อนกดอนุมัติเสมอ (หรือใช้โหมด manual review)
- **ผลลัพธ์ต้องตรวจ** — โค้ด สเปรดชีต หรือ PDF ที่เอเจนต์สร้าง ควรมีคนทวนก่อนใช้งานจริง

## สรุป — เหมาะกับใคร

**เหมาะกับ:** คนที่อยากใช้เอเจนต์ AI แต่ไม่อยากส่งโค้ด/เอกสารขึ้นคลาวด์, คนมีการ์ดจอหรือ Mac Apple Silicon อยู่แล้ว, ทีมที่อยากลองโอเพนซอร์สโมเดลตัวไหนก็ได้กับงานจริง

**ไม่ค่อยเหมาะกับ:** เครื่องสเปกต่ำ (ควรใช้เอเจนต์คลาวด์อย่าง Freebuff แทน), คนที่อยากได้คำตอบแกร่งสุดๆ ทุกครั้ง (โมเดล local ยังสู้ frontier model ไม่ทั่วถึง)

โดยรวม Bionic คือการเติมชิ้นส่วนที่หายไปของวงการ local LLM — ก่อนหน้านี้เรามีโมเดลเก่งๆ บนเครื่อง แต่ไม่มี "ตัวกลาง" ที่จับมันมาทำงานได้จริงแบบ Claude Code หรือ Codex ตอนนี้มีแล้ว และเป็นทางเลือกที่คุมข้อมูลได้เองครับ
